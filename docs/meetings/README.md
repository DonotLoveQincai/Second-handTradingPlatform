每周一 20:00、30 分钟线上会，**D 负责记录**。文件名用当天日期：`2025-10-27.md`。

## 记录规则（三条，别写多）

1. **只写"谁、做了什么、卡在哪"**，不要写讨论过程
2. 每个"卡住了"必须有**责任人 + 截止时间**，否则下次开会还是它
3. 契约一旦在会上改了，当场把结论写进 `docs/01-契约.md`，**D 提一个 `docs:` 开头的 commit**
